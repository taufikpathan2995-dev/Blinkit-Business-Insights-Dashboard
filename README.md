# Blinkit Sales & Business Insights Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze Blinkit grocery sales data and generate meaningful business insights.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Data Visualization

## Dashboard Features
- Total Sales, Average Rating and Average Sales per Outlet KPIs
- Sales by Item Type
- Sales by Fat Content
- Sales by Outlet Type
- Sales by Outlet Tier
- Top 10 Items by Sales
- Item Visibility vs Sales
- Interactive Slicers and Filters

## Project File
`Blinkit_Business_Dashboard.pbix`

## Objective
To analyze grocery sales performance, compare outlet categories, and identify top-performing products through interactive visualizations.
